
# 网页数据抓取
- 目标是从网页抽数据
    - 噪声多,弱标签,可能是无用信息
    - 好处是数据量比较大
    - 比如,网上买东西的时候比较价格
- 很多ML数据集也包括了从网页抓取的数据
    - 比如,ImageNet,Kinetics
- 网页爬取 VS 提取
    - 爬取:索引互联网所有页面
    - 提取:从web网页提取关注的数据

# 抓取的工具
- curl通常没用,网站的所有者会尝试不同的方法去禁止抓取
- 使用headless浏览器,一个没有GUI的浏览器
- 需要大量的新IP,能够轻松地从云服务商中获取

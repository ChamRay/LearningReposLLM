

# 数据标注流程
```shell
1. 是否有足够的数据?
是,下一步
否,返回上一步(数据获取)
2. 需要提升标注/数据或者模型?
数据或者模型,进入下一阶段
标注,下一步
3. 足够的标签?
是,半监督学习
否,下一步
4. 是否有钱?
是,找众包帮助标记数据
否,下一步
5. 没有标注
发挥主观能动性,弱监督学习
```

# 半监督学习
- 关注只有小部分数据是标注了的,大部分数据还没有标注
- 使用无标签数据,需要对数据分布做出一些假设:
    - 连续型假设:样本间具有相似性,可能具有相同的标签
    - 聚类假设:数据通常按照类进行分布,同类数据可能具有相同标签
    - 流型假设:数据的复杂性可能比看到得要低,可以通过降维来获取一些更干净的数据

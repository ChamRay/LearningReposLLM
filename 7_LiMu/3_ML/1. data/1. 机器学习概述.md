

# 机器学习的应用
## 工业界中的机器学习
- 十几年前,主要是大公司在用ML
- 很多依靠机器学习来推动收入增长的公司都会这样做。
    - 主要的行业领域包括:高科技 汽车 制造业 零售 金融以及医疗健康
    - 新冠疫情加速了这一过程

## 房屋售价预测
- 目标是为最终买房者预测拍卖价

# 机器学习工作流
```shell
Problem formulation->Collect&process data->train&tune models
                        |                           |
                      Monitor        <-       Deploy models

```
# 挑战
- 问题定义:关注利润最大化问题
- 数据:高质量的数据是很难的,可能也比较私密
- 模型训练:模型越来越复杂 数据越来越大,越来越贵 
- 模型部署:大量计算不适用于实时推理
- 监控:模型训练时看到的数据分布,和实际部署后遇到的数据分布不一样

# 模型中的角色
- 领域专家:懂商业业务,知道什么数据比较重要,以及知道在什么地方用模型
- 数据科学家:全栈,在数据处理,模型训练和部署都能干
- 机器学习专家:定制化机器学习
- 软件开发工程师:开发/维护数据管线,模型训练工程化

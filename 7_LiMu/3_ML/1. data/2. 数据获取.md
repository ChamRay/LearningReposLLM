
# 数据获取流程
```shell
开始一个机器学习应用

1. 是否有足够的数据?
是,进入后续步骤(数据标注)
否,下一个
2. 能不能找到其他能用的数据源
是,发掘和融合数据
否,下一个
3. 有其他方法生成数据吗?
是,生成数据
```

# 发现哪些数据可用
- 找已有的数据集
- 寻找基准数据集,用来评估一个新的想法
    - 比如,需要找到一个调试超参数的数据集,找不同类型的小规模或者中规模数据集
    - 比如,需要做一个非常大的深度神经网络,则需要找非常大的数据集
- 收集新数据
    - 例如,覆盖不同的驾驶场景的驾驶视频

# 常见的机器学习数据集
- MNIST:美国Census Bureau员工手写数字
- ImageNet:图片搜索引擎获取的百万级的图片数据集
- AudioSet:Youtube上面一些声音的切片,用于声音的分类
- Kinetics:Youtube上视频的切片,用于人类行为分类
- KITTI:记录无人驾驶中摄像头以及其他传感器的数据集
- Amazon Review:亚马逊评论的数据集
- SQuAD:Wikipedia中的问答对
- LibriSpeech:有声读物的数据集

# 从哪里获取数据集
- Paperswitchcodes Datasets:学术数据集
- Kaggle Datasets:数据科学家上传的机器学习数据集
- Google Datasets Search:网站上的搜索数据集
- Various toolkits datasets:tensorflow huggingface
- Various confrence/company ML competitions
- Open Data on AWS:100+ 大规模原始数据集
- 公司中的数据湖

# 数据集的比较
- 学术的数据集:数据已经经过清洗,难度适中;通常规模较小,选择面比较小
- 竞赛的数据集:相比学术,更接近实际应用;数据集也很干净,选择面依旧较小
- 原始数据集:比较灵活;需要更多的精力进行预处理

# 数据集成
- 将不同数据源的数据组合成一个比较一致的数据
- 生产数据通常存储在不同的表
    - 例如,一张表记录房子的信息,另一张表记录销售信息,还有一张表记录代理信息
- 通过实体ID键(主键)来Join数据
- 键的信息一般关注:身份证ID,没有的行,重复列,数据有冲突

# 生成数据
- GANs:生成图片数据
- Data augmentations:数据增强,对基准图片做不同的增强

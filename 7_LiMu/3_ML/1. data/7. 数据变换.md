
# 实数值特征的数据归一化处理
1. 限定在一个区间(a,b)
x = (x-min(x))/(max(x)-min(x))*(b-a)+a
2. Z-score,0 mean,1 standard deviation
x = (xi-mean(x))/std(x)
3. 10倍率缩小
x = x/(10**j)
4. log缩小计算量级
x = log(xi)

# 图片的转换
- 图片数据的主要成本在于存储
- 下采样或者截取
    - 减小图片尺寸以保存以及更快的加载
    - ML在低分辨率的作用比较好
    - 降低图片的质量(jpeg),可能有1%的精度下降
- 图片黑白化
    - 冗余更小
    - 模型更快

# 视频的转换
- 视频的平均时长:电影大约两小时,Youtube大约11分钟,Tiktok大约15s
- 预处理要平衡存储 质量以及加载速度
- 常处理成短视频切片,10s以下,每个切片通常包含一个事件
- 解码视频,采样序列帧
    - 加载优先,则需要十倍多的空间
    - 使用CPU解码计算比存储便宜
    - 可以应用其他图片转换方法到帧处理

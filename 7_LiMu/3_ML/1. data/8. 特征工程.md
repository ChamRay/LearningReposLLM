
# 特征工程
- ML算法比较喜欢固定长度的输入和输出
- 特征工程是在DL出现之前,ML的关键步骤
- DL训练通过深度神经网络去提取特征,自动完成特征抽取

# 表数据特征
- 数值型:可以直接用或者切分成n个唯一的数字
- 分类数据:独热编码(只有一列的数字为1,其余为0)
- 时间数据:统一时间格式,不同时间区间
- 特征组合:把两个特征组合起来(笛卡尔积)

# 文本数据特征
- 文本已经转换成词元
    - bag of words:词元进行独热编码后,把出现的次数加起来;但是会丢失时序信息
    - word embeddings:把词表示成一个向量,向量表示有语义信息
- 预训练语言模型
    - GPT,BERT;计算开销比较大

# 图片/音视频数据特征
- 传统通过手动提取图片特征,比如:SIFT
- 现在通常使用预训练的深度神经网络提取特征

# HPO 算法:黑盒或Multi-fidelity
- Black-box:对于每次训练任务当做一个黑盒在HPO中,每次都把训练过程完成
- Multi-fidelity:让训练任务提速
    - 在采样子集上训练,理论上好的模型在小数据上效果也挺好
    - 降低模型大小,假定超参数对模型的影响差不多
    - 配置超参数在效果不好的时候直接尽早停止

# 最常见的两个搜索策略
## 网格搜索
    对space中的每一组值,都遍历一遍,把最好的值返回
    有维度诅咒,在空间比较大的时候几乎不可能完成
## 随机搜索 
    对space中随机选取n次进行搜索,返回最好结果
    n取得比较合适,一般取
    随机搜索是很有效的方法,相较于网络搜索

# 贝叶斯优化 Bayesian Optimization
- BO:迭代训练会学习一个从HP到目标函数的一个函数,基于上一次训练,根据当前模型评估选择下一次训练
- Surrogate模型
    - 拟合超参数到目标函数
    - 概率的回归模型;随机森林;高斯过程
- 获取函数
    - 获取均值大表示怎么置信,但是目标函数比较高
    - 为下一次训练采样获取函数最大的点
    - 平衡探索和利用
- BO的局限性
    - 在初始化时,和随机搜索差不多
    - 优化过程是时序的,意味着无法并发训练提速

# Succesive Halving
- 核心是有很多超参数选择,只选择核心的超参数优化
- 随机选择n个超参数把数据扫m遍
- 重复直到:
    - 保持最好的n/2超参数再去训练一遍 m epoch
    - 再保持剩下的1/2,即n/4,再去训练一遍m epoch
    - 即任务减半,留下最好的一半模型
- 选择n和m基于训练预算,直到覆盖完整的训练

# Hyperband
- 在SH
    - n意味着探索
    - m意味着利用
- HB跑了多个SH,每次减少n并且增加m
    - 优先考虑更多的探索,再去做更多的利用(已知的好结果)

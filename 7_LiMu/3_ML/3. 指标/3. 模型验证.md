
# 泛化误差
- 实际中,我们会选择一个测试数据集,它上面的误差用来评估泛化误差
- 这个测试数据集只能用一次
- 验证数据集,可以被使用多次

# 常见生成验证集的办法
- 随机切分训练集和验证集,在训练集上训练模型,在验证集上算误差,用验证上的误差或指标来近似泛化误差,用于选择模型选择
- 一般会随机选择n%的数据集用作验证集.n可以为(10,50)%

# 非IID数据的切割
- 随机切割可能不起作用
- 时序数据,比如房子售价 股价,验证集应该在训练集时序之后
- 样本属于同一个组,比如同一个人的不同照片
- 数据不是一个平衡的,比如某些类特别多

# K折交叉验证
- 通常没有足够数据切分验证
- 方法:把数据切分成K份,1份用作验证集,K-1份用作训练集
- 通常选择:K=5/10

# 常犯错误
- 个人选择:90%的情况下特别好,是因为ML的bug造成的,最大的问题是验证集被污染了
- 验证集有来自于训练集的样本,重复的样本被分到训练和验证集
- 信息泄漏

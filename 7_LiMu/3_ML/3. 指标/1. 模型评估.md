
# 模型指标
- 在监督学习中,我们通常训练损失值最小的模型;损失值通常被用来衡量模型好坏的指标
- 还有其他很多指标
    - 模型特性:在分类任务的时候评估模型精度;评估mAP对回归任务
    - 商业特性:请求响应时间;保证应收的增长
- 通常会选择多个指标来评估模型

# 分类任务的指标
- 精度:sum(y==y_hat)/y.size,y_hat表示正确预测的元素(包含正例以及反例)
- 准确度:sum((y_hat==1)&(y==1))/sum(y_hat==1),对于关注的类别,预测正确在所有预测成关注类的占比
- 召回率:sum((y_hat==1)&(y==1))/sum(y==1),对于关注的类,预测成关注类对这个类的占比
- F1 score:平衡准确度和召回率,做一个调和平均



# 手动超参数调参
- 选择一个质量比较高的基线开始,比如高质量工具包中的默认设置,或者论文中的值
- 调整一个超参数的值,再次训练观察变化
- 重复几次以获得显著效果
    - 哪个超参数比较重要
    - 模型对超参数的敏感度怎样
    - 什么是好的范围
- 需要关心实验管理
- 保存训练日志和超参数的比较,分享以及之后可重现
    - 最简单的方法就是记录日志并且把关键指标保存成表格
    - 更好的方法,比如tensorboard以及weights&bias
- 重现是很难的,取决于
    - 环境,硬件&依赖库
    - 代码
    - 随机算子


# Neural Architecture Search(NAS)
- 一个神经网络有很多不同类型的超参数
    - 拓扑结构:ResNet,MobilNet,即层数
    - 每一层上:kernel_size,卷积层的通道数,全连接层或者循环神经网络中的隐藏层
- NAS尽量自动化整个神经网络的设计
    - 整个NN的搜索空间是什么样
    - 如何在整个搜索空间搜索
    - 衡量性能

# One-shot Approach
- 即学习模型架构,也学习超参数
- 构造并训练一个模型同时包含众多模型
- 评估候选架构
    - 只关心候选模型结果的排名
    - 使用一个近似指标,在数据上训练出来的精度
- 把比较好的模型拿出来再重新完整地训练一次

# 调节CNN
- 一个CNN有三个方法可以调节
    - 深度:更多的层
    - 宽度:更多的输出通道
    - 更大的输入:提升输入图片的大小/分辨率
- EfficientNet提出综合的提升方法
    - 三个东西一起动

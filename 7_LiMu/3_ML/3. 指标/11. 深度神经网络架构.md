
# 深度神经网络调参
- DL是一门从数据中抽取信息的编程语言
    - 超参数的值会在数据训练之后填充
    - 可微分
- 多样的设计模式,从网络层级到网络架构

# 批量归一化
- 数据标准化使得线性回归损失更平滑
- 批量归一化对中间层的输入也做了标准化

# 批量归一化拆解
- reshape:变形,将数据编程2D
- 归一化:对每一列进行标准化
- recovery:还原步,按照需求调整
- 输出相同的shape数据

# 层归一化
- 把BN用在RNN里时,每个时间步t的数据分布可能不一样,所以通常要给每个时间步单独保存一套均值和方差
    - 当序列非常长的时候,在推理阶段会带来问题,处理比较麻烦
- 层归一化变形的时候,除了需要考虑时间步之外,其他rest和NM一样
    - 标准化每个样本,到当前的时间步骤
    - 训练阶段和推理阶段保持一致
    - 因Transformer而广泛流行

# 更多其他归一化
- 对于变形
    - instanceNorm
    - groupNorm
    - crossNorm
- 对于归一化:白化
- 对于还原步骤
- 应用权重或梯度

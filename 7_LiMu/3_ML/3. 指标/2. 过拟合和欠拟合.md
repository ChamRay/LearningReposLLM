
# 训练误差
在训练期间产生的误差

# 泛化误差
对新数据预测产生的误差


# 过拟合
对于简单数据,使用了是一个非常复杂的模型,记住了所有数据,导致对新数据效果不好


# 欠拟合
对于复杂数据,使用了一个非常简答的模型,无法训练出适配的模型,导致对新数据没有效果

# 模型复杂度
- 去拟合各种各样模型的能力
- 比较不同的算法之间的复杂度很难
- 如果模型在同一个类中,还是能做一些比较的

# 模型复杂度的影响
根据已有的经验,模型越简单,训练误差越大;模型越复杂,泛化误差越大

# 数据复杂度
- 多因素相关
- 同样的,很难去对不同的数据进行比较

# 模型选择
- 需要选择和数据具有差不多复杂度的模型
- 先选择模型类别,再选择模型超参数
